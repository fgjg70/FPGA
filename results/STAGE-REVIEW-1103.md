## 3. 三个真正的风险（按杀伤力排序）

### R-1 🔴 位流只写进 FPGA RAM，**Flash 未写** —— 唯一能让所有工作归零的风险

`BOARD_VALIDATION.md` 明确：*"Flash未写入，断电后RAM配置丢失"*；仓库里也**没有任何 flash/pdi 烧写路径**
（`build.py` 只负责构建，下载是手工 JTAG 客户端）。
决赛是"**现场作品介绍及演示**"——评委断电重上电，黑屏即演示失败。

**今晚必做（二选一，优先 A）**：
- **A**：PDS 生成 Flash 配置（`.pdi`/SPI-Flash 工程）并烧入 → 上电自启动，复刻 Artix 在 10-17 做到的 QSPI 自启动；
- **B**（兜底）：现场流程固化为"上电 → JTAG 下载 2 分钟"，**并准备备用笔记本 + 下载脚本 + 位流哈希**，同时**录一段上板演示视频兜底**。

### R-2 🔴 主口径数字与远端代码对不上

1. **合规器件上的 CoreMark 实测原始成绩不在仓库**（`coremark_hardware.json` 不存在；`ACCEPTANCE.md` 只说"使用者已完成 CoreMark 跑分，保留其原始成绩"）——**报告写不出赛题 1.4 要求的跑分结果**。
2. **远端 `tools/build_sw.py` 仍是 `-Os`**：

   ```
   origin/main:  cm_defs = ['FLAGS_STR="-Os -march=rv32im -mabi=ilp32"']
   本地 main:    CM_OPT = '-O2 -mbranch-cost=1 -fira-loop-pressure'
   ```
   ⇒ **克隆 GitHub 仓库复现不出 405.9**，只有一行之差。RTL 本身两侧**逐字相同**（`core.sv` 无差异），所以这是纯配方问题、零风险、必须推上去。
3. **Pango 的 CoreMark 固件已经用了 `-O2`**（`build.py: common = [... "-O2" ...]`）⇒ **还没有叠加我们在 Artix 上实测的两个开关**（`-mbranch-cost=1 -fira-loop-pressure`，Artix 上 −0.507% ticks）。这是**零成本**的第二步提升。

### R-3 🟠 硬性提交物形态不合格

Word/PDF 技术文档 + 演示视频，两个都没有。24 小时够做，但**必须现在开工**，不能等性能收尾。

## 5. 接下来 24 小时**不要**做的事

1. **不要合并两条线的 RTL**：Pango 是 **Verilog-2005 移植**，Artix 是 SystemVerilog 原核，两边 regfile/乘法器/取指实现都不同，T-24h 合并 = 引入全新风险。
2. **不要再追频率**：Pango 125 MHz 已 WNS +0.609 很健康；Artix AI 档 125 MHz 差 0.077 ns 的那点收益不值得再烧 2 小时综合。
3. **不要重开 4.2 CM/MHz**：已算术判死（CHANGELOG §17.3/§18.4/§19）。
4. **不要在 Pango 上试 RV32C/A**：C 会把取指地址变成"穿存储器 + 13 级 LUT"（Artix 上实测 fmax −32.2%），PDS 下不可控。
5. **不要把 405.9 写成实测**：那是派生值，硬件实测是 324.19。

## 6. 评审意见（直说）

**技术上：这个项目已经不是"能不能做出一个像样的 RISC-V"的问题了。**
PG2L100H 上 125 MHz 的 CPU + 50 MHz 的自研 INT8 NPU + 摄像头/LCD/跨时钟桥的完整应用闭环，
在 Artix-7 之外再开一条合规器件路线，而且已经拿到"摄像头画面上屏"这种只有实物才有的证据——
**这个完成度在往届里不低**。

**但按"能不能拿分"的顺序看，剩下 24 小时的价值分布是反的**：
跑分再多涨 5%，不如把 Flash 写进去（决定决赛现场黑不黑屏）、
把 CoreMark 主口径数字捞进仓库（决定报告 1.4 能不能填）、
把 Word/PDF 和视频做出来（决定初审能不能过形式审查）重要得多。

**⇒ 我的建议：今晚停止一切 RTL 与综合工作**，按 Stage-0 → Stage-1 → Stage-3 的顺序推进，
把 Stage-2 的 CoreMark 实测放在明早。Git 收口和报告/视频这两件事**今天必须开始**，
因为它们不需要任何仿真或综合时间，但占满了一个人的一整个晚上。
