## v1→v2 差异说明（与上一版报告 1,320,062 的 30,000 拍差从哪来）

上一版估算 = v1 估算(1,216,578, 旧 plan 108 op/105 HW) + v2 流水化增量(103,484) = 1,320,062。
**错在基准 plan 过期**：新 plan（T-model 精度修复后）把 18 个 shortcut-add 改成 `cpu_add`（CPU 执行），NPU 不再跑；旧 v1 估算里这 18 个 HW add 的周期（约 0 拍）被当成 NPU 周期带进基准，而 v2 增量又按105 个 HW op加了一遍 +7/op 等，于是多算。

**正确口径**：逐 op 套 v2 公式（本文件脚本），只计真正跑 NPU 的 op：conv 55 + dwconv 28 + pool 3 + upsample 1 = **87 个 HW op**；`cpu_conv0/cpu_concat/cpu_add` 均不计。
