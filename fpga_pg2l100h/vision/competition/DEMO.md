# 三分钟演示脚本与答辩准备

三分钟是本项目的材料组织目标。最终格式和资格时间以当届赛事通知为准。录像注明开发板、时钟、模型、光照和距离，保留连续操作；界面仿真截图必须标明仿真。

| 时段 | 演示内容 |
|---|---|
| 0:00～0:20 | 料箱数字标签核验需求，展示PG2L100H、OV7670、J11 LCD；说明电脑不参与推理 |
| 0:20～0:45 | 空场READY，设置期望3，呈现3，红框与DIGIT 3，MATCH，OK加1 |
| 0:45～1:10 | 同张标签保持，计数不变；不移走直接换4，显示REMOVE |
| 1:10～1:35 | 移走后再呈现4，WRONG、BAD加1；改工单后重新空场核验 |
| 1:35～1:55 | 遮挡、模糊与非数字，展示拒识及实际失败边界，不剪掉不利表现 |
| 1:55～2:15 | 串口事件与CRC32输入采集，说明训练/测试实体隔离 |
| 2:15～2:45 | CPU流水线、NPU算术一致性、CoreMark及PDS真实资源/时序报告；未测项明确标注 |
| 2:45～3:00 | 独立测试样本量、误放行/拒识/延迟、当前边界及下一步 |

答辩材料应回答：为什么用FPGA；CPU做了什么而硬件做了什么；网络为什么选这个规模；如何证明权重参与推理；如何测50 MHz真实周期；单帧结果与业务判定如何区分；为什么保留失败案例；模型何时会把字母误认为数字；为何连续投票不能证明错误概率立方下降。

手势数量核验作为实验附加演示：SW4长按1秒或串口g切换，顶部必须显示HANDTEST EXP；先清场，再呈现1～9，底部为HAND 1～HAND 9，l切回标签。保留拒识、误分类和切换清除旧框的过程，单列九类人物隔离测试。当前开发验证35.14%正样本正确接受，不应在三分钟主线中声称已经可靠识别全部手势；先完成真实相机补数和验收，再决定展示时长。

不能宣称“通用YOLO移植”“工业零误检”“所有手写人适用”“达到国赛二等奖”。可核实的贡献是自研RISC-V上的定点检测加速、原始输入可追溯、保守核验流程、完整验证与资源/效率分析。
