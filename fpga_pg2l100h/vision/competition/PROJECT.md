# 数字料箱标签防错核验终端 NUMGUARD

本项目选择《全国大学生嵌入式芯片与系统设计竞赛2026 FPGA创新设计赛道选题指南（紫光同创）》的**选题一：基于紫光同创 RISCV 指令集 CPU 设计**，以数字料箱核验作为高阶 AI 加速应用。指南 PDF 第10～11页要求 RV32I、不少于三级流水、外设、CoreMark、资源和性能分析；第10页高阶任务明确提出 RISC-V + 边缘 AI + 传感器/显示设备。原有自研 CPU 与摄像头、LCD 可以直接形成完整系统。若赛事组织方对自备板或选题归属另有要求，以书面确认为准。

## 应用边界

工位一次呈现一张黑字白底的单个数字标签，数字0～9代表十种料箱类别。操作者先设定本工单期望类别；相机识别实际数字，连续稳定后给出 MATCH 或 WRONG，并记录一次核验事件。移走标签、确认空场后才允许下一次计数。打印标签是主任务，手写数字作为同一数字语义下的扩展验证。增加手势1～9的独立实验模式，演示同一工位的数量手势核验；其当前误分类较多，必须单列统计。多位料号、自然场景通用物体、危险品与安全防护均不在本版范围内。

关键设计是“采集 → 定点检测 → 质量门限 → 连续一致性 → 工单比对 → 去重计数 → 本地显示与审计”。类别判断不使用工单期望值作先验，以免把错料强行判为正确。模糊、低分、类别接近、相机失效等情况必须进入 WAIT/UNCERTAIN，而不是猜一个结果。连续投票不能消除同一错误的反复出现，因此仍需独立的错料误放行统计。

## 平台

- PG2L100H / -6 / FBG676，复用原 MES50HP 的 RV32IM 处理器。
- 实物18针DVP OV7670接J7，当前约束按针号1～18逐号重映射；AN430 480×272 RGB LCD接J11。旧22针AL422假设已根据2026-11-02照片纠正，接线详见 `../CAMERA_DEBUG.md`。
- CPU、采集、INT8加速器50 MHz；视频扫描27 MHz，LCD像素时钟9 MHz；活动工程全部采用Verilog。
- 64×64灰度输入，自定义6层YOLO风格数字检测网络，21672字节INT8权重。
- 模型与固件放板上初始化存储器；电脑仅用于下载、可选串口审计及数据采集，不参与推理。

## 争取国赛二等奖的验收线

以下均为项目目标，不能写成已经达到的成绩。奖项由真实作品、答辩、赛题符合性与评审决定。

| 维度 | 应完成的证据 |
|---|---|
| CPU基础 | RV32I/M功能回归、流水线冲突/分支波形、异常/中断支持边界说明 |
| CPU性能 | 官方CoreMark，正确校验、运行不少于10秒；记录迭代次数、实际时钟、CoreMark/MHz与CoreMark/LUT |
| AI硬件 | 相同INT8权重/输入的逐值一致性；纯NPU周期与CPU完整处理周期分开记录 |
| 识别 | 按实物标签/字体/拍摄会话划分训练、验证、测试；10类混淆矩阵、拒识率、错料误放行率 |
| 工程 | 冷启动、断接、复位、空场、错料、模糊、重复呈现、串口命令与工单切换测试 |
| PDS | 目标芯片综合、布局布线、DRM/APM/LUT/FF资源、时序报告和可下载位流 |
| 演示 | 无电脑推理的连续实物演示；3分钟以内1080P视频、可复现源码、实验记录和答辩材料 |

初始实物验收建议：至少30张不同实体标签、3个独立拍摄会话、3种照明/距离条件；至少300次正确料、300次错误料、300次空场/非数字干扰。真实测试集全程隔离。记录每次成功、拒绝、错误，不删除不利样本。目标可设正确料有效核验率≥95%、错料误放行率≤1%，但零次错误/300次试验并不证明误放行概率为零，应同时给出样本量和统计区间。最终目标在采集基线后修订。

## 当前证据与待完成部分

现有平台有RGB565采集、LCD叠加、RV32固件和INT8算子的仿真基础。早期混合12类模型保留为历史资料，当前分别部署数字标签模型和新训练的手势专用模型。数字报告必须保留“合成图像，不是实物精度”的标记；手势报告必须说明37张独立原照片的148个验证变体中仅52次正确接受、66次误分类、30次拒识，尚不能作为可靠数量确认功能。两模式共享50 MHz NPU，通过按键/串口切换，手势标记HANDTEST EXP，实验方案见 `../model/GESTURES.md`。

截至本项目建立时，尚无本工程PG2L100H布局布线、时序收敛、位流、板上识别精度与功耗的证据。完整PDS和许可证到位后再生成这些结果。使用者已完成CoreMark跑分，保留其原始成绩及测试条件；本轮不要求重跑。硬件加速比和国赛奖项不预填数值。
