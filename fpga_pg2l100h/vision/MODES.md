# 三种识别模式与按键

CPU目标125 MHz，NPU和MMIO为50 MHz。摄像头J7、LCD J11及传感器180度旋转配置保持当前接线。三种模式共用实时预览，由CPU选择任务。

| 模式 | LCD标题 | 当前模型情况 |
|---|---|---|
| 0：手写数字0～9 | HANDWRITE | 使用现有INT8数字模型，包含MNIST和打印字训练；权重偏向打印字，真实摄像头手写精度未验证 |
| 1：北方数字手势1～10 | GESTURE | 接口支持用户参考图的1～10，十为双手食指交叉；当前装载旧九类实验权重，新十类模型待实拍训练 |
| 2：COCO80物品 | COCO80 / NO MODEL | 已缓存原版预训练权重并完成主机架构核算；板端算子、量化和后处理未完成，当前禁止推理 |

长按SW4一秒后松开，按0→1→2→0循环；持续按住只产生一次切换，必须松开再按才进入下一模式。短按SW4选择数字模式的期望数字，在COCO80模式忽略。SW5切换彩条，SW6冻结/恢复，SW7重新配置摄像头，SW2复位到模式0。

串口115200、8N1：`h`或兼容命令`l`选择手写，`g`选择手势，`o`选择COCO80，`m`切换下一模式。串口确认分别为 `MODE HANDWRITE 0-9`、`MODE HAND 1-9`（通过十类模型校验后为1-10）、`MODE COCO80 MODEL NOT LOADED`。状态行MODE字段为0、1、2，READY为该模式固件是否有可执行模型。

模式切换重置快照/NPU，取消排队的显示提交，隐藏旧框，清除连续确认、当前数字、分数和待导出的旧输入。数字模式重新要求确认空场后才计数，累计OK/BAD和事件序号保留。不存在模型的模式既不读取旧分类结果，也不输出事件或计数。再次进入数字模式恢复其实际bank。

COCO80模式保持正常相机预览，顶部显示NO MODEL，底部显示MODEL NOT LOADED。相机配置失败等硬件诊断仍有显示优先级。当前固定引擎只有两个模型bank、22个类别槽和64×64单通道输入；第三个菜单选项并未把它变为80类引擎。具体缺口见 `model/COCO80_FEASIBILITY.md`。

应用模式寄存器为0xA100005C的低两位；已部署能力寄存器0xA1000064固定为0x3。状态0x04位8与LCD面板位25表示未部署。面板位24:23携带模式，原手势位23在模式1保持兼容。值2及保留值3均在硬件中阻止快照和NPU执行。显示仍沿用272位跨时钟完整包，避免模式、框和文字分开更新。

验证包括实际生产固件的9/10类头文件测试、全部数字解码、循环切换和未部署模式禁止读结果；SoC仿真使用实际RV32固件、125/50 MHz时钟、去抖按键和INT8引擎，检查忙时取消及完整模式循环。LCD仿真检查NO MODEL提示并防止旧框、旧标签出现在物品模式。仿真和本机PDS构建不能代替实物按键及独立识别数据验收；最新执行状态以本轮验证记录为准。
